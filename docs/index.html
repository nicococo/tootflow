// Features

Everything included.
Nothing gated.

📅

Campaigns & scheduling

Pick a template, tone, language, and cadence. TootFlow spaces posts across your campaign duration — pause, resume, and reschedule any time.

🤖

AI drafts, your control

AI generates the draft schedule; you edit every word. Per-post refinement with natural-language instructions. 10 templates, 12 tones, 3 languages.

🐘

Mastodon + X

One platform per campaign. Mastodon: OAuth, polls, multi-account linking. X: publish via your own X API keys — the Free tier is enough.

⏰

Set-and-forget publishing

A background scheduler checks every minute and publishes due posts. Transient errors retry automatically; permanent ones fail visibly.

📊

Engagement metrics

Favourites, boosts, replies, and follower snapshots — tracked per post with weekly charts, so you know what actually landed.

📤

Export Studio

Turn a finished campaign into a newsletter digest, a LinkedIn article, or a Reddit post. Your content, second life included.

// Quickstart

From clone to first campaign
in about five minutes.

tootflow — self_host.sh 
# 1. Clone and configure
git clone https://github.com/nicococo/tootflow.git
cd tootflow
cp .env.example .env
#    → set SECRET_KEY and APP_BASE_URL

# 2. Run it (SQLite, zero extra setup)
docker compose up -d --build

# 3. Open the app and log in with Mastodon
http://localhost:8000

# Optional: PostgreSQL instead of SQLite
docker compose --profile postgres up -d --build
// Bring your own model

Your AI. Your key. Your costs.

🔑

Any OpenAI-compatible provider

Paste a key on the Account page and point it at OpenAI, OpenRouter, or a local Ollama instance. Keys are encrypted at rest and used only for your own requests — the operator of a hosted instance never pays for your tokens.

🛟

Instance fallback

Running it just for yourself? Set OPENAI_API_KEY in the environment and skip per-user setup entirely. Per-user keys always win over the instance default when both exist.
